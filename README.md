# epa-hf-qsar-rdf

RDF integration for EPA Hydraulic Fracturing Study toxicity/QSAR workbooks from Data.gov. Source metadata declares CC0.

Authoritative agency reference values and explicitly measured EPI Suite inputs are typed as reference/experimental evidence. TOPKAT values, EPI Suite estimates, selected modeled properties, confidence scores, rankings, and MCDA scores are explicitly typed as model-derived prediction or decision-analysis values. FracFocus counts are occurrence summaries. No prediction is presented as an experimental observation.

Every populated source cell is retained in the evidence graph. Canonical CAS links use Identifiers.org. n-Hexane (`110-54-3`) includes TOPKAT LOAEL predictions and EPI Suite measured/estimated property context.
